# Code of Conduct

SCODE is an open-source project and we want its community to be practical, welcoming, and technically constructive.

Please be respectful, specific, and helpful. Critique code, design, and behavior — not people.

Unacceptable behavior includes harassment, threats, discriminatory or demeaning language, deliberate disruption, spam, publishing another person's private information, or posting passwords, API keys, tokens, private files, or other secrets.

This applies to Issues, Discussions, pull requests, and other SCODE community spaces.

For conduct concerns, contact **support@sidra-ai.com**. For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of posting details publicly.
